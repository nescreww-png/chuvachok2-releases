# Чувачок 2.0

Пиксельный помощник для Windows: управляет компьютером, музыкой и играми голосом. Речь распознаётся офлайн.

## Установка
1. [Скачать установщик](https://github.com/nescreww-png/chuvachok2-releases/releases/latest/download/ChuvachokSetup2.exe)
   и запустить. Права администратора не нужны.
2. При первом запуске Чувачок скачает модели речи (~270 МБ) — прогресс видно в его пузыре.
3. Скажи **«чувачок»** или нажми **Ctrl+Alt+Пробел** — и команду: «следующий трек», «громкость 40»,
   «открой дискорд», «сверни все окна», «какая погода», «напомни через 20 минут выключить чайник».

Обновления ставятся сами. Правой кнопкой по Чувачку — персонаж, танец, настройки.
Нашёл баг — пришли файл `%LOCALAPPDATA%\Chuvachok2\chuvachok.log`.
